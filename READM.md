# ChronoLog

### Make your time visible.

ChronoLog is a calm, simple time and activity tracker that helps you understand where your day goes. Start a timer as you begin an activity, add something you forgot to track, and see the shape of your day at a glance.

> **A clearer picture of your time — one activity at a time.**

## Your day, at a glance

- **Track as you go.** Choose a category, add an optional note, and start the timer. Your running timer is restored if you reload the page.
- **Fill in the gaps.** Add or edit an activity with its date and start and end times. ChronoLog catches invalid times and overlapping entries.
- **Make it yours.** Start with Work, Study, Leisure, Sport, Sleep, and Other, or add your own categories.
- **Look back with clarity.** Choose a date to view its activities, total tracked time, time by category, and a simple distribution chart.
- **Stay in control.** Edit or delete entries whenever plans change.

## Designed to feel clear

ChronoLog keeps the experience focused: readable summaries, a responsive layout, and straightforward controls that work across screen sizes. When a day is still empty, it offers a gentle nudge to get started.

## Your data stays with you

ChronoLog stores activity records and categories in your browser’s local storage. There’s no account, backend, or external service. Your data is available in this browser on this device.

## Get started

```bash
npm install
npm run dev
```

Run the core logic tests with:

```bash
npm test
```

Build the production app with:

```bash
npm run build
```
